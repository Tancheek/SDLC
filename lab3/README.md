# Лабораторная работа №3 — бизнес-требования

- **Дисциплина:** «Жизненный цикл разработки программного обеспечения»
- **Проект:** SVS-RVC — студия синтеза поющего голоса
- **Автор:** Ананьева Татьяна Михайловна, группа 450501
- **Ветка:** `lab3`

## Цель работы

Задокументировать бизнес-требования к разрабатываемому ПО, подготовить графическую часть
средствами SysML v2 и провести ревью требований с заказчиком через pull request.

## Графическая часть

Диаграмма вариантов использования и мокапы построены по SysML v2-моделям и сохранены в PNG. Все изображения связаны
с разделами SRS:

- раздел 2.7 — бизнес-требования и их трассировка на REQ.

## Ревью

Ветка `lab3` предназначена для pull request. Замечания заказчика (напарника и
преподавателя) фиксируются в обсуждении PR; конструктивные принимаются, отклонённые
обосновываются. История изменений документа ведётся в разделе «История изменений» SRS.
