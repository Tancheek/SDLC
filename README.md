## Что входит в лабораторную работу

- изучение возможностей интегрированной среды разработки;
- создание и настройка проекта C++ с графическим интерфейсом на Qt 6 Widgets;
- разработка приложения «Конвертер белорусских рублей в евро» по варианту 1;
- применение архитектурного паттерна MVC с активной моделью;
- сборка, запуск и отладка приложения;
- подготовка UML-диаграммы классов и модели на языке SysML v2;
- оформление отчёта по лабораторной работе.
