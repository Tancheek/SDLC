## Описание проекта

SVS-RVC — десктопное приложение и C++-библиотека для синтеза поющего голоса по нотной партитуре и тексту с переносом тембра целевого певца методом RVC.

На вход система получает MIDI-партитуру (ноты, длительности, силу) и текст (лирику или слоги), а на выходе формирует WAV-аудио поющего голоса с выбранным тембром. Поддерживаются два режима:

- пакетный офлайн-рендер всей песни;
- real-time-мониторинг — озвучивание партии в реальном времени.

## Основные возможности

- импорт MIDI и текста, фонетический фронтенд и привязка слогов к нотам;
- построение F0-контура с поддержкой вибрато, портаменто и глиссандо;
- акустический синтез вокального сигнала;
- перенос тембра методом RVC: HuBERT/ContentVec, индексный поиск и генератор;
- DSP-постобработка и экспорт в WAV/FLAC;
- управление RVC-моделями и проверка их целостности;
- графический интерфейс и CLI для пакетного рендера.

## Технологии

- C++17 и выше;
- CMake;
- Qt 6 Widgets для графического интерфейса;
- локальные вычисления без обязательного сетевого подключения.
