## Краткое содержание

SVS-RVC — Windows-приложение для синтеза вокальной партии по MIDI-партитуре и
тексту с переносом тембра RVC. Модель динамического поведения включает:

* **2 актёра:** композитор/продюсер и владелец голоса; заказчик/слушатель — стейкхолдер.
* **7 прецедентов:** импорт MIDI и лирики с привязкой слогов, выбор и проверка
  RVC-модели, рендер, прослушивание, экспорт WAV/FLAC, сохранение проекта,
  управление библиотекой моделей.
* **4 UML-диаграммы:** вариантов использования, активности, состояний и
  последовательности; все исходники — в текстовом Mermaid-формате.
* **Глоссарий (30 терминов)** и **дополнительную спецификацию (20 требований)**.
